# Bug Reports

This folder contains sample defect reports identified during manual testing of fintech/mobile banking applications.

The defects demonstrate practical experience in:

* Functional defect reporting
* Validation issues
* Financial transaction testing
* Notification failures
* Session persistence issues
* Authentication defects
* Calculation validation
* User experience issues

Each bug report includes:

* Bug ID
* Module
* Severity
* Priority
* Reproduction Steps
* Expected Result
* Actual Result
* Status

The artifacts demonstrate hands-on experience with defect identification, root cause analysis, and QA reporting practices.
