# Test Cases

This folder contains manual test case artifacts demonstrating validation of customer-facing, financial, and operational workflows within a fintech/mobile banking application.

The test cases were designed to validate system functionality, business requirements, financial accuracy, and user experience across critical workflows.

Testing includes positive, negative, validation, edge case, security, and end-to-end scenarios.

---

## Test Coverage

The following modules were covered:

### Login & Authentication

* Valid login
* Invalid credentials
* Session timeout
* Password masking
* Security validation
* Unauthorized access prevention

### Registration & Onboarding

* OTP verification
* Identity verification
* KYC validation
* Session persistence
* Onboarding recovery
* Accessibility testing

### Funds Transfer

* Internal transfers
* Interbank transfers
* Beneficiary management
* Transfer validation
* Reversal handling
* Duplicate transaction prevention

### Goal Savings

* Savings creation
* Auto-save validation
* Retry logic
* Interest accrual
* Withdrawal handling
* Maturity validation

### Fixed Deposit

* Investment creation
* Interest validation
* Early liquidation
* Tax deduction validation
* Maturity processing
* Withdrawal workflow

### Notifications

* Push notifications
* Email notifications
* Reminder validation
* Trigger verification
