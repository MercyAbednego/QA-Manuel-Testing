# Fixed Deposit Test Cases

## Overview

This folder contains manual test cases for a **Fixed Deposit / Investment Plan feature** within a fintech/mobile banking application.

The scenarios validate investment creation, maturity handling, interest calculation, tax deduction, early liquidation, notifications, PDF certificate generation, and administrative approval workflows.
