Login Test Cases

This folder contains manual test cases for login and authentication functionality.

Coverage includes:

Valid Login
Invalid Credentials
Empty Fields Validation
Password Masking
Show/Hide Password
Session Timeout
Account Lock
Biometric Authentication
Network Failure Handling
Security Testing (SQL Injection)
Unauthorized Access Prevention
Backend Error Handling
Login Drop-off Recovery

The scenarios include positive, negative, edge, validation, and security test cases.
