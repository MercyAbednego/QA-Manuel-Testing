# QA Manual Testing Portfolio

## Overview

Welcome to my **Manual Testing Portfolio Repository**.

This repository showcases my hands-on experience in **Manual Software Testing** for fintech/mobile banking applications, including test design, defect reporting, regression validation, user acceptance testing (UAT), and test execution reporting.

The goal of this repository is to demonstrate practical QA knowledge across complex financial workflows, business validations, transaction processing, and customer-facing features.
